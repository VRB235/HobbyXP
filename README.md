# HobbyXP

Aplicación de escritorio WPF (.NET 8) para gamificar hobbies personales (running, gym, entretenimiento, libros, logros).

## Documentación

Estado detallado del proyecto, arquitectura y pendientes: **[docs/ESTADO-PROYECTO.md](docs/ESTADO-PROYECTO.md)**

## Requisitos

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Ejecutar

```powershell
cd src\HobbyXP
dotnet run
```

La base de datos SQLite se crea en `%LocalAppData%\HobbyXP\hobbyxp.db`.
